### Consolidated Findings

#### CRITICAL SECURITY (fix immediately)

1. **Unauthenticated email API endpoint** — `apps/league-builder/src/app/api/email/route.ts` has `CORS: *` and no auth check. Anyone can send emails through it.
2. **Staff API route missing auth** — `apps/league-builder/src/app/api/staff/route.ts` has no session verification.
3. **Roster PATCH/DELETE missing auth** — roster management endpoints lack auth middleware.
4. **Client-side payment_status trust** — `apps/league-sites/src/lib/actions/registration-payments.ts` trusts client-supplied payment status instead of verifying via Stripe.

#### CRITICAL FUNCTIONAL (broken features)

5. **Delete Team is non-functional** — handler is empty, button does nothing.
6. **Scorekeeper timer is non-functional** — hardcoded "20:00", never counts down.
7. **Draft Room: empty `handleExport`** — export buttons in completion modal do nothing.
8. **Draft Room: auto-pick timeout is a no-op** — timer expires, nothing happens, draft stalls.
9. **Draft Room: pick clock hardcoded to 90s** — ignores actual draft settings.
10. **Draft Room: RosterConfirmation position grouping broken** — always shows "Unknown".
11. **Draft Room: no draft order management UI** — server action exists, no UI calls it.

#### HIGH — UX/Performance

12. **`force-dynamic` defeats caching** in league-sites — every page load hits the DB.
13. **`return null` instead of `notFound()`** on 5+ league-sites pages — blank screen instead of 404.
14. **Venues page N+1 query** — fetches teams per venue in a loop.
15. **No `loading.tsx` suspense boundaries** anywhere in league-sites.
16. **No i18n in draft room** — 100+ hardcoded English strings, violates bilingual requirement.
17. **Draft room is desktop-only** — no responsive breakpoints, breaks under 1024px.
18. **No confirmation dialogs** for start draft, make pick, undo pick.
19. **Draft race condition** — multiple `fetchDraftData` calls on reconnect can overwrite state.
20. **Player pool capped at 200** — no pagination, larger leagues lose players silently.

#### MEDIUM — Systemic Issues

21. **i18n coverage is ~20%** — only 2 of 9 features use translation keys. Massive gap.
22. **Currency inconsistency** — some code uses USD, platform is Canadian (CAD).
23. **`packages/auth` is an empty stub** — exports nothing, every app rolls its own auth.
24. **PWA doesn't use shared data layer** — duplicates queries from `packages/data`.
25. **30+ console.log in league-wizard server action** — should be removed for production.
26. **6 duplicate Supabase client instances** in draft room components.
27. **Excessive `as any` type assertions** across draft room — types out of sync.
28. **No structured data / sitemap** in league-sites — SEO gap.
29. **No error boundaries** in league-sites — unhandled errors crash entire page tree.
30. **CSV export doesn't escape commas/quotes** — malformed output for names with commas.
