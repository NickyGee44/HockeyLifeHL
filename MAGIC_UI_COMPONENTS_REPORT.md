## Implementation Notes

### Dependencies Required

Most components require:
- `framer-motion` or `motion/react` - Animation library
- `react-use-measure` - Element measurement
- `class-variance-authority` - Component variants
- Existing shadcn/ui components (Button, Card, Badge, etc.)

### Theming Considerations

All components support:
- CSS variable-based theming (compatible with existing league color system)
- Dark/light mode support
- Custom color overrides via Tailwind classes

### Performance Notes

- Sliding Number: Very performant, uses CSS transforms
- Stats Widget: SVG-based, lightweight
- Advanced Gradient Button: Heavy (Three.js) - use sparingly
- Glass effects: Require `backdrop-filter` support (modern browsers)
